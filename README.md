# ✝️ Christianity Post & Blog Platform

A content-driven blog platform built with **Python**, **Django**, and **MySQL**. This project is a complete back-end migration and rebuild of a previous website, transitioning from a proprietary CMS (Wix) to a self-hosted, scalable relational database architecture.

🌐 **Live Application:** [https://christianity-post.onrender.com/](https://christianity-post.onrender.com/)

---

### 🌟 Project Overview

The **Christianity Post** web application serves as a structured repository for articles, post categorizations, and community engagement. The primary goal of rebuilding this platform from scratch was to achieve full control over database modeling, routing logic, site performance, and backend data integrity.

---

### 🚀 Key Features

- **Dynamic Article Management:** Database-backed post creation, editing, and dynamic page rendering.
- **Category & Tag Organization:** Relational database schemas for categorizing content by topics and themes.
- **Relational Data Integrity:** Designed with foreign key constraints, indexing, and ORM query optimization using MySQL.
- **Clean Architectural Pattern:** Built using Django's Model-View-Template (MVT) pattern for separation of concerns.
- **Responsive Frontend Integration:** Styled with custom HTML5 and CSS3 for optimal readability across desktop and mobile devices.

---

### 🛠️ Tech Stack

- **Backend Framework:** Python 3, Django
- **Database Management:** MySQL (using Django ORM)
- **Deployment Platform:** Render
- **Frontend & Styling:** HTML5, CSS3, JavaScript
- **Version Control & Tools:** Git, GitHub

---

### 🏗️ Architecture & Rebuild Journey

#### 1. Migration from CMS to Custom Django Stack
- **Original Stack:** Wix (No Direct Database Access or API Control).
- **New Stack:** Python, Django, MySQL.
- **Motivation:** Gained full authority over data schemas, removed third-party platform limitations, optimized page delivery speeds, and enabled custom back-end feature development.

#### 2. Database Schema Design (ORM)
The core database models encompass:
- `Post`: Stores article content, publish timestamps, slug-based URLs, and featured flags.
- `Category`: Categorizes articles dynamically using relational mapping.
- `User / Author`: Manages author attributes and posting permissions.
